# 🪩 ERRDAY 7080 나이트 (MVP)

브라우저에서 바로 들어가는 7080 나이트/캬바레 가상 클럽. A-Frame 1.5 + Node(Express + Socket.IO).

## 실행 (Windows)
1. Node.js LTS 설치: https://nodejs.org
2. 폴더 압축 풀고 **`실행.bat`** 더블클릭 → 처음엔 자동 `npm install` → 브라우저가 `http://localhost:8080` 으로 열림
   (직접 실행: `npm install` → `npm start`)

## 관리자 (음악 관리)
- 관리자 비밀번호는 **제작자가 정한 고정 비밀번호**입니다(서버 콘솔엔 표시하지 않음). 바꾸고 싶으면 환경변수 `ADMIN_PASSWORD`로 덮어쓸 수 있습니다.
- 위쪽 **🔑** → 비밀번호 입력 → 음악 패널에 MP3 업로드·유튜브 링크 추가·▶/⏸/⏭·전체 대기열(곡 선택·🗑 삭제)이 나타납니다.
- **🔀 랜덤 재생**(켜기/끄기): 켜면 다음 곡을 남은 곡 중 무작위로 고르고, 한 바퀴 다 돌기 전엔 반복하지 않습니다. **섞기**는 대기열 순서를 한 번 섞습니다(지금 곡은 맨 위 유지). 서버가 정하므로 모두 같은 곡을 듣습니다. 켜져 있으면 지금 곡 표시 앞에 🔀가 붙습니다.
- 일반 손님에게는 **지금 나오는 곡 제목과 재생 상태만** 보입니다(대기열은 관리자만).
- 서버를 재시작하면 관리자는 다시 로그인해야 하고, 재생 목록도 비워집니다(파일은 uploads/에 남음).

## 사용법
- **입장**: 닉네임, 남/여, 의상 3종(성별에 따라 다름), 옷 색, 피부색. 입장 화면에서 내 캐릭터를 미리 볼 수 있습니다. 가구 모델을 받는 동안 「3D 모델 불러오는 중… n/m」 표시 후 입장 버튼이 켜집니다. **⚙**에서 언제든 변경 → 모두에게 반영.
- **캐릭터**: 보내 주신 그림을 참고해 코드로 직접 만든 2등신 캐릭터(외부 모델 아님): 큰 동그란 머리, 따뜻한 살구빛 피부, 갈색 점 눈과 눈꺼풀 선, 작은 주황빛 코, 작은 미소, 둥근 귀, 짧은 몸, 동그란 손. 의상 이름은 남녀 모두 **정장 / 디스코 / 한복**.
  - 남자 정장: 짧은 옆가르마, 남색 스트라이프 정장, 흰 셔츠, 와인색 넥타이, 흰 행커치프, 갈색 로퍼
  - 남자 디스코: 큰 아프로, 반짝이는 흰 오픈 칼라 셔츠, 갈색 벨트, 무지갯빛 반짝이 나팔바지, 은색 통굽 구두
  - 남자 한복: 검은 갓(의상의 일부), 초록 저고리 + 짙은 갈색 고름, 갈색 바지, 흰 버선, 검은 신
  - 여자 정장: 풍성한 웨이브 머리, 라벤더 그레이 어깨 뽕 블레이저 + 스커트, 흰 이너, 남색 플랫슈즈
  - 여자 디스코: 큰 곱슬머리, 로열블루 지퍼 점프슈트, 반짝이 나팔 밑단, 은색 통굽 구두
  - 여자 한복: 가르마 쪽머리 + 초록 비녀, 색동 소매, 연두 저고리, 보라 고름, 다홍 치마
  - 옷 색은 의상별 기본색(그림과 같은 색)으로 시작하고, 원하면 바꿀 수 있습니다. 피부색 4가지.
- **자동 춤**: 서서 3초 가만히 있으면 춤 3가지(흔들흔들 / 디스코 손가락 / 고고 트위스트) 중 하나를 랜덤으로 춥니다. 음악이 나오면 비트에 맞춰 더 빠르게. 움직이거나 앉으면 멈추고, 다른 사람에게도 같은 춤이 보입니다.
- **시점**: 3인칭. PC는 마우스 드래그 = 회전, 휠 = 줌. 폰은 한 손가락 드래그 = 회전, 두 손가락 벌리기/오므리기 = 줌. 카메라는 벽 밖으로 나가지 않게 당겨집니다.
- **이동**
  - 바닥 **클릭/탭** → 노란 표시가 생기고 그 자리로 걸어갑니다(드래그와 탭은 자동 구분). 테이블·바·무대·화분은 피하고, 완전히 막히면 멈춥니다.
  - PC는 WASD/방향키(카메라 방향 기준). 누르면 자동 걷기는 취소됩니다. 폰은 오른쪽 아래 화살표 버튼도 있습니다.
- **무대**: 앞쪽 가운데 계단으로 무대에 올라가서 걷고 춤출 수 있습니다(높이가 계단 따라 자연스럽게 바뀌고 다른 사람에게도 보임). 무대 바닥을 탭하면 계단을 거쳐 올라가고, DJ 부스는 장애물입니다.
- **앉기(자동)**: 의자/소파/**바 스툴**을 **클릭·탭하면 걸어가서 앉습니다.** 의자 0.8m 안에서 멈춰 있어도 자동으로 앉습니다. 움직이면(WASD·다른 곳 탭) 자동으로 일어납니다. E/Esc 키도 가능. 다른 사람에게도 앉은 모습이 보입니다.
- **채팅**: 하나의 전체 채팅. 걷든 앉든 언제든, 머리 위 말풍선. 입력 중엔 이동 키가 먹지 않습니다. 폰은 💬 버튼으로 채팅창 열고 닫기, 🎵 버튼으로 음악 목록.
- **내 소리 🔊/🔇 + 볼륨**: 위쪽 바. **나한테만** 적용(다른 사람·공유 재생엔 영향 없음), 브라우저에 기억됩니다. 다시 켜면 지금 공유 재생 위치로 맞춰 재생합니다. MP3·유튜브 모두 적용.
- 브라우저 정책상 소리는 「입장하기」 또는 화면의 「🔊 탭해서 소리 켜기」를 눌러야 납니다(특히 폰).

## 음악: MP3 + 유튜브 (관리자)
- MP3 업로드(최대 30MB) 또는 **유튜브 영상/재생목록 링크**를 붙여넣고 「추가」. 다운로드 없이 공식 YouTube IFrame 플레이어(숨김)로 각자 브라우저에서 재생합니다.
- 서버가 현재 곡·시작 시각을 관리 → 늦게 들어온 사람도 같은 위치로 맞춰짐. ▶/⏸/⏭·곡 선택·삭제는 MP3/유튜브 공통.
- 재생목록은 API 키 없이 유튜브 페이지에서 곡 목록을 읽어옵니다(**최대 100곡 정도, 첫 페이지만**). 제목은 oEmbed로 가져옵니다.
- 퍼가기 금지·삭제·비공개·연령 제한 영상은 재생이 안 되어 「⚠ 유튜브 재생 불가 → 다음 곡」 안내 후 자동으로 넘어갑니다.
- 한계: 유튜브 광고가 끼면 그 사람만 잠깐 늦어질 수 있음(5초마다 자동 보정), 「믹스」 자동 재생목록·비공개 목록은 못 읽음, 유튜브 페이지 구조가 바뀌면 재생목록 읽기가 깨질 수 있음(단일 영상 링크는 계속 됨), 서버를 끄면 목록이 비워짐. 저작권은 유튜브 약관을 따르며, 공개 영업장에서 틀 경우 별도 공연권이 필요할 수 있습니다.

## 휴대폰
- 같은 Wi-Fi에서 PC 주소(아래)로 접속. 화면 크기에 맞게 채팅/음악은 버튼으로 접고 펴며, 키보드가 올라와도 화면이 줄어들도록 설정했습니다. 폰에서는 화면 해상도와 조명을 낮춰 가볍게 돌립니다.

## 친구 초대 (같은 Wi-Fi)
서버 창에 `같은 Wi-Fi 친구 접속: http://192.168.x.x:8080` 이 표시됩니다. 그 주소를 친구 폰/PC 브라우저로 열면 됩니다.
(안 열리면 Windows 방화벽 알림에서 Node.js "개인 네트워크 허용", 또는 `ipconfig`로 IPv4 주소 확인)

## 무료 배포 (외부 친구)
- **Render** (Web Service 무료): GitHub에 올리고 Build `npm install`, Start `npm start`, 환경변수 `ADMIN_PASSWORD`. 15분 미사용 시 잠들고 업로드 파일은 재시작 때 사라짐.
- **Railway / Koyeb / Fly.io**: 비슷한 방식(무료 크레딧/한도 있음). Glitch는 2025년 앱 호스팅 종료.
- **집 PC + 터널**: `cloudflared tunnel --url http://localhost:8080` 또는 ngrok → 임시 공개 주소. 가장 간단.

## 테스트 (개발용)
`tests/admin-chat.test.js`: 서버 실행 후 `npm i -D puppeteer-core socket.io-client` → `node tests/admin-chat.test.js` (크롬 경로는 환경변수 CHROME). 관리자로 로그인한 PC·폰 화면에서 채팅을 보내 다른 접속자에게 도착하는지 확인합니다.
- 고친 문제: 폰에서 관리자 로그인 시 음악 패널이 자동으로 열려 채팅창을 덮던 문제 → 로그인 시 자동으로 열지 않고, 채팅/음악 패널은 하나만 열리며 채팅 입력칸을 누르면 채팅이 앞으로 옵니다.

## 구조
`server.js`(웹·소켓·업로드·유튜브·관리자) / `public/index.html, style.css, world.js(공간·모델), app.js(아바타·이동·채팅·음악)` / `public/models/`(CC0 3D 모델) / `uploads/`
참고: networked-aframe 대신 Socket.IO로 직접 동기화했습니다(최신 버전 호환·설치 단순화).
